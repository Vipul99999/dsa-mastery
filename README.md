## ✨ Why This Repo?
- ✅ **Production-Ready Code**: Clean, optimized, and heavily commented implementations.
- 📊 **Complexity Analysis**: Every algorithm includes `Time` & `Space` complexity breakdowns.
- 🎯 **Interview Focused**: Curated problem sets mapped to FAANG-style interview patterns.
- 🔍 **Visual & Intuitive**: ASCII diagrams, step-by-step walkthroughs, and edge-case coverage.
- 🧪 **Tested**: Unit tests included for core implementations.

## 🗂️ Repository Structure
```
📦 dsa-mastery/
├── 📁 arrays/              # Static/Dynamic arrays, sliding window, two pointers
├── 📁 linked-lists/        # Singly, Doubly, Circular, Fast/Slow pointers
├── 📁 stacks-queues/       # Stack, Queue, Deque, Monotonic variants
├── 📁 trees/               # BST, AVL, Heaps, Tries, Segment Trees
├── 📁 graphs/              # BFS, DFS, Dijkstra, Kruskal, Topological Sort
├── 📁 sorting-searching/   # Quick, Merge, Radix, Binary Search variants
├── 📁 dynamic-programming/ # 1D/2D DP, Memoization, Knapsack, LCS, LIS
├── 📁 backtracking/        # Permutations, Subsets, N-Queens, Sudoku
├── 📁 greedy/              # Interval scheduling, Huffman, Activity selection
├── 📁 practice-problems/   # Categorized by difficulty & pattern
├── 📁 scripts/             # Test runners, complexity analyzers, generators
└── 📄 README.md            # You are here
```

Each directory contains:
- `README.md` → Concept explanation & visual diagrams
- `implementation/` → Language-specific code
- `tests/` → Automated test cases
- `problems.md` → Linked practice questions & solutions

## 🚀 Getting Started

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/Vipul99999/dsa-mastery.git
cd dsa-mastery
```

### 2️⃣ Setup & Run Tests (Python Example)
```bash
cd arrays/two-pointers/
python -m pytest tests/ -v
```

### 3️⃣ Pick a Topic & Practice
1. Read the concept guide in the folder's `README.md`
2. Study the implementation
3. Run the provided tests
4. Solve the linked practice problems
5. Track your progress in `practice-problems/progress.md`

## 📈 Recommended Learning Path
| Phase | Focus | Estimated Time |
|-------|-------|----------------|
| 🔹 **Basics** | Arrays, Strings, Complexity Analysis | 1–2 weeks |
| 🔹 **Core DS** | Linked Lists, Stacks, Queues, Hash Maps | 2–3 weeks |
| 🔹 **Algorithms** | Sorting, Searching, Recursion, Two Pointers | 2 weeks |
| 🔹 **Intermediate** | Trees, Heaps, Graphs, BFS/DFS | 3–4 weeks |
| 🔹 **Advanced** | Dynamic Programming, Backtracking, Greedy | 3–4 weeks |
| 🔹 **Interview Prep** | Pattern recognition, Mock interviews, Optimization | Ongoing |

💡 **Pro Tip**: Solve 1–2 problems daily. Focus on *patterns*, not memorization.

## 🤝 How to Contribute
Contributions are what make open source amazing. Here's how to get started:

1. **Fork** the repo & create your branch: `git checkout -b feat/add-avltree-java`
2. **Follow the style guide**: Consistent naming, comments, complexity annotations
3. **Add tests**: Every new algorithm must pass existing & new test cases
4. **Update docs**: Link your implementation in the topic `README.md`
5. **Submit a PR**: Use the provided template. Mention issue numbers if applicable.

📖 Read the full guide: [`CONTRIBUTING.md`](CONTRIBUTING.md)  
🐛 Found a bug or typo? Open an issue!  
💡 Have an idea? Start a discussion.
